## Reproduce

```bash
export COREPACK_HOME=$PWD/.corepack
export PATH="$HOME/.npm-global/bin:$PATH"
corepack pnpm install

corepack pnpm typecheck
corepack pnpm lint
corepack pnpm test              # 77 tests: unit + read-only mainnet + Anvil fork
corepack pnpm probe             # rewrites chain-probe.json and sources snapshot data
corepack pnpm verify            # rewrites verification-evidence.json
corepack pnpm fork:authorization
corepack pnpm fork:upload
node scripts/verify/tapekit-kernel-crosscheck.mjs /tmp/TapeKit_inspect 2.2.0.tape
```

The TapeKit kernel cross-check needs a checkout at the pinned commit (e.g. clone it to
`/tmp/TapeKit_inspect`); the CLI records `status: "skipped"` when it is absent.

## Honest limitations

- `VERIFIED` is a statement about **one pinned block**, not an L2 finality guarantee.
- The live site used for P0-06 is a third-party site; TapeCI has not deployed to mainnet (P0-07).
- Evidence JSONs record mutable observations (fees, live site bytes, processor count); re-run to
  refresh, and never treat an old JSON as current chain state.
- The chain does not enforce declared hashes/sizes or path canonicalization; those checks are
  client-side (see `docs/P0_DECISION.md` §4).
